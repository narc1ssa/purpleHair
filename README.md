# Эфирия · Хроники островов

Браузерный платформер на трёх иллюстрациях из репозитория. Игра начинается на интерактивной карте мира. Выберите **«Лесная тропа» → «Начать уровень»** и доведите Лиру до фиолетового портала.

## Запуск

Нужен Node.js 22.12+ (или 20.19+). Серверная часть, внешние API и аккаунт не нужны.

```sh
npm ci
npm run dev
```

Откройте адрес, который напечатает Vite. Для публикации выполните `npm run build` и разместите содержимое `dist/` на статическом хостинге. `npm run preview` позволяет проверить собранную версию.

## Как играть

| Действие                           | Клавиши                                    |
| ---------------------------------- | ------------------------------------------ |
| Бежать                             | **A / D** или **← / →**                    |
| Прыгнуть                           | **Пробел**                                 |
| Подняться / спуститься по лестнице | **W / S** или **↑ / ↓**, рядом с лестницей |
| Спрыгнуть сквозь платформу         | **↓ + Пробел**                             |
| Магический заряд                   | **F**                                      |
| Пауза                              | **Esc**                                    |

На телефоне есть экранные кнопки. Уход с вкладки ставит игру на паузу. Карту можно перетаскивать, приближать колесом или щипком; кнопка с прицелом возвращает к выбранному уровню. Клавиатурой: **Tab** для выбора метки, **Enter** для подтверждения, стрелки для перемещения сфокусированной карты, **+ / −** для масштаба.

- На старте доступен только **уровень 01**. Портал открывает следующий маршрут.
- Платформы повторяют верхние контуры островов и мостов. У каждой лестницы есть верхняя и нижняя площадки. Каждый слизень разворачивается у краёв **своей** платформы.
- Монстры отнимают сердца при касании. Их можно перепрыгнуть, обезвредить прыжком сверху или магией. После падения Лира возвращается к последней путевой точке, потеряв сердце.
- За финиш, выполнение цели по монетам и прохождение без урона даётся по звезде. Звёзды пополняют запас кристаллов.
- Все **8 уровней — маршруты на основе одной предоставленной карты** `Level1_map.png`, с разными стартами, целями и патрулями. Первый ведёт от нарисованного старта к исходным финишным вратам.
- Дневник показывает открытые уровни и личные рекорды. Лучшие результаты и настройки хранятся в `localStorage` этого браузера (`aetheria.atlas.v1`). Повторное прохождение улучшает рекорд, а не дублирует награду. Незавершённая попытка не сохраняется.

## Устройство проекта

- `src/data.js` — маршруты, точки на карте мира, платформы, лестницы и места появления объектов. Игровые координаты приведены к ширине **1250**; для координат в исходной карте 5000 × 3333 используйте коэффициент 4.
- `src/physics.js` — независимая от DOM симуляция с фиксированным шагом 1/120 с: движение, столкновения, лестницы, патрули, сбор монет, здоровье и финиш.
- `src/game.js` — Canvas 2D, камера, анимация персонажа, эффекты, физическая клавиатура и мультитач.
- `src/atlas.js` — выбор уровня, панорамирование и масштабирование карты.
- `src/main.js`, `src/store.js` — игровой интерфейс, пауза, дневник и сохранения.
- `assets/` — готовые облегчённые игровые слои, спрайты и локальные шрифты. Во время игры сетевые ресурсы сторонних сервисов не запрашиваются.

### Исходные рисунки

Оригинальные PNG не изменены. Из `map_all.png` подготовлен фон атласа, из `Level1_map.png` — игровой мир, слизни и монеты, из `sprites_hero.png` — прозрачные кадры бега и магии. Нарисованные неподвижные копии интерактивных объектов убраны из фоновых слоёв.

Готовые WebP входят в проект. Если нужно пересобрать их после замены рисунков:

```sh
python -m venv .venv
. .venv/bin/activate
pip install pillow numpy opencv-python-headless
python tools/prepare_art.py
```

Lora и Manrope распространяются по SIL Open Font License; тексты лицензий находятся в `assets/fonts/`.

## Проверка

```sh
npm test
npm run build
```

Тесты проверяют опору и прыжки, оба направления лестниц, границы патрулей, урон, сбор монет, сохранение и последовательное открытие уровней. Первый маршрут проходится тестом обычными игровыми действиями; достижимость остальных проверяется графом перемещений, построенным настоящей физикой игры.
